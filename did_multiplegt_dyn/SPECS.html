Test specifications

Every specification the test suite runs: 121 estimations and 14 input checks, written as the Stata commands that produce the reference results. R and Python run the same specifications (translated through specs/option_map.csv) and every result is compared with Stata's. How to run them: TESTING.html. Known differences: DIFFERENCES.html.

Each spec starts with use data/<dataset>.dta, clear from the suite's data/ folder; graph_off is added to every command. This page is generated from specs/specs.csv by specs/make_specs_page.py.
